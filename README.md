## ✨ المميزات الرئيسية (Features)

- ⚡ **قاعدة بيانات MongoDB NoSQL:** دعم كامل ومعالجة مرنة للبيانات والوثائق غير المنتظمة.
- 🎨 **تصميم زجاجي وعصري (Glassmorphism & Neon UI):** واجهة مستخدم تفاعلية وجذابة للغاية باستخدام Tailwind CSS.
- 🖼️ **دعم صور الغلاف:** إمكانية إضافة رابط صورة مخصصة لكل مقال أو توليد صور تقنية عصرية تلقائياً عبر Unsplash.
- 🏷️ **نظام وسوم ذكي (Smart Tagging):** فصل الكلمات تلقائياً لتحويلها لوسوم تفاعلية ملونة عند الإدخال بفاصلة أو مسافة.
- ⏱ **حساب وقت القراءة التقديري:** احتساب وقت القراءة تلقائياً بناءً على عدد كلمات المقال.
- 💬 **نظام تعليقات متكامل:** قسم تعليقات قابل للطي والتوسيع مع حماية الصلاحيات.
- 🔒 **نظام صلاحيات وآمان:** حصر تعديل وحذف المقالات والتعليقات بمالك المقال/المستخدم المسجل فقط.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Back-End:** Laravel Framework
* **Database:** MongoDB (using `mongodb/laravel-mongodb` package)
* **Front-End:** Blade Templates, Tailwind CSS (CDN), Google Fonts (Readex Pro)
* **Tools:** MongoDB Compass / Shell
